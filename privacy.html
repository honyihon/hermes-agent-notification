Privacy Policy

Last updated: 2026-10-28

Data we access

Hermes Agent Notification accesses only the Google account data needed for the permissions (scopes) the user explicitly grants on the Google consent screen, solely to send notifications to that user.

How data is used

Data is used only to provide the notification feature. It is not used for advertising, profiling or any other purpose.

Storage and sharing

OAuth tokens are stored on the operator's own server and are not shared with, sold to or transferred to any third party. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke access at any time at https://myaccount.google.com/permissions. To request deletion of stored data, email the contact below.
