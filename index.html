Hermes Agent Notification

Hermes Agent Notification is a personal automation tool operated by honyihon. It sends notifications about the status of self-hosted AI agent tasks to the owner's own Google account.

How it uses Google data

The app signs in with Google OAuth only to perform the notification actions the user has authorized. It does not sell, share or transfer Google user data to third parties, and it does not use the data for advertising.
